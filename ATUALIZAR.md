2. Abra a raiz do repositório GitHub e use Add file > Upload files.
3. Envie TODO o conteúdo extraído diretamente na raiz, incluindo app, lib e demais pastas, e confirme Commit changes. Não envie a pasta externa nem o ZIP.
4. Mantenha Root Directory vazio na Vercel. Aguarde o deploy automático do novo commit.
5. O banco Roselyne já foi atualizado. Não precisa executar SQL ou alterar variáveis.
6. Crie uma tarefa, clique Concluir tarefa e abra Concluídas. Confira a data, o tempo e a persistência após recarregar. Editar uma concluída deve preservar a conclusão.
