# Relato para a entrega

Organizei o teste pelos requisitos: cadastro e listagem, edição e exclusão, pesquisa, validações e preparação da publicação. Mantive uma única tela para facilitar o uso e reduzir a complexidade.

Utilizei Next.js, React, TypeScript, CSS e PostgreSQL no Supabase. A aplicação foi preparada para hospedagem na Vercel. Usei o Codex como apoio amplo de IA para desenvolver o código, preparar a documentação e executar verificações. Ainda estou desenvolvendo minha autonomia em programação e usei este projeto como oportunidade de estudo.

Priorizei as funcionalidades exigidas, validações no formulário e servidor e dados salvos no banco. Cada navegador tem sua própria lista, sem cadastro de conta. A pesquisa considera título e descrição, a descrição é opcional e datas passadas são permitidas por serem válidas.

Antes de enviar, revise o relato para refletir exatamente seu estudo. Depois de confirmar a publicação, substitua “foi preparada para hospedagem” por “foi publicada” e acrescente os links reais do GitHub e da Vercel.
